## Android 收口

应用内中文文案迁入 Android 字符串资源，包括数据层错误与演示问题。字符串提取不改变 JSON 字段名或服务端提供的病历、问诊和医生名称。

页面网络动作在冷却期间灰禁，包括登录、同步、分诊、查询、挂号、退号、问诊与档案加载。按钮分别保存业务可用状态与冷却状态；倒计时结束不会把仍在请求中、已完成或无余号的动作重新启用。当前页及旧页返回的429均立即刷新公共倒计时；已打开的系统确认弹窗按钮不在页面注册表内，但 API 层仍阻止冷却期网络请求。

挂号新建、幂等重放及退号结果在「我的就诊」保留可截图提示，不再仅依赖 Toast。退号未确认归还、状态异常及失败使用警示提示；退出、切账号/演示模式或更换服务地址会清除结果。此提示保存在当前 Activity 内存，不承诺进程重启恢复。

稳定控件 ID 前缀为 `com.smart.hospital.patient:id/`：`login_name`、`login_password`、`login_submit`、`login_message`、`cooldown_banner`、`appointment_outcome`。测试方应按 ID 定位输入与证据，避免固定坐标误把密码追加到登录名。L-2 在外部报告中仍是取证缺口，不能据文件名把它改写为已证实的冷却缺陷；本轮不宣称设备验证通过。

构建脚本仅在 local.properties 实际内容变化时写入，仍保留其他配置键；没有运行构建或签名校验。
