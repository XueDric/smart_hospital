## 二、是否基于已有项目或开源项目二次开发
- **否，本项目为自研实现**：未 fork 任何同类作品，没有从其它医院 App / 挂号系统复制代码；业务模型（号源与挂号独立 MySQL 路径、乐观锁令牌、就诊状态机、病历锁定 + 解锁重写）由团队设计与实现（决策链见 `docs/adr/ADR-0001-号源与挂号独立MySQL路径.md`）。
- **仓库内置两份源码副本，且都不是业务代码**：轻舟 QingZhou（仓颉 Web 框架，MIT）—— `server/third_party/qingzhou/`，**这个框架由本团队自研**，四组框架级实现（`be569cd` 参数化绑定静默改值、`c9a41e8` 连接隔离与失败恢复、`310fd4f` 路由/静态错误体可注入、`181921b` 断链自愈与探活），快照与上游逐字节一致，见 [轻舟说明](轻舟说明.md)；MariaDB 驱动（Apache-2.0）—— `server/third_party/mariadb-driver/`，静态编译进 exe，属纯第三方组件。两者的来源、commit、改动与许可证见 [第三方许可说明.md](第三方许可说明.md) §1.1/§1.2 与各自的 `PROVENANCE.md`。框架侧提交全部由 XueDric（申宇乐）完成（`git log --oneline -- server/third_party/qingzhou`），属框架自身实现（MIT 开源，版权署名 `Copyright (c) 2026 guowei, BIT Foundational Software And Systems Lab`）。
- **UI 无第三方框架、素材无外部来源**：鸿蒙端零 ohpm 依赖，安卓端 `dependencies {}` 为空（无 AndroidX / Compose），管理台是手写 HTML/CSS/JS（零 npm）；无外部图片/字体/数据集，位图仅 DevEco 模板默认图标（见 THIRD-PARTY.md §7）。

## 六、自己复算的命令
```powershell
git rev-list --count HEAD                 # 提交数
git shortlog -sne HEAD                    # 按提交的成员统计
git shortlog -sne HEAD -- server/src      # 按模块的成员统计
git ls-files | Measure-Object             # 跟踪文件数
git log --reverse --format='%h %ad %an %s' --date=short | Select-Object -First 1   # 首个提交
```
