## 三、这次做了什么（B 方案：只动编码层，不重录）

## 四、仍然没解决的问题（如实记）

1. **字幕压住界面**：字幕是**硬字幕**，字号偏大，在预问诊页压住了"主诉·最多 200 字"与"提交并继续"按钮，在管理端压住侧栏"退出登录"。不重录无法修（裁切会切掉 UI）。
2. **时间轴不连续**：状态栏时钟在片内出现 `10:54→10:55→10:56→10:49→…→10:52→11:23→10:53` 的跳变，说明是**多段录制拼接**。评审若逐帧看会发现不是"一次过"。
3. **内容是 Mock 模式**：见 §二。片头已声明，但**没有展示真实服务链路**（起库、起服务、真实分诊落库）。
4. **没有安卓端**：片尾字幕写的是"鸿蒙端运行视频到此结束"，安卓端只有截图证据（`release/android/`）。
5. **没有起库/起服务画面**：仓库自己的分镜建议里第一步是 `devdb.ps1 start` + 服务端启动 + `/health`，片中没有。
6. **容器元数据带 `AIGC` 块**（`ContentProducer` / `ProduceID`）：本片是剪辑工具合成产物；画面是应用真实渲染，但这条元数据与 [AI 工具使用声明](AI-工具使用声明.md) 原来的"未使用 AI 生成视频素材"表述**需要对齐**（已在声明里改为如实口径）。

## 五、要重录时的清单（A 方案）

如果时间允许重录，按这个顺序一遍过，能一次把 §四 的 1–5 全部消掉：

1. **整片只录一次**（不要拼接），录前把模拟器时钟对准，避免时间跳变。
2. **先用在线服务跑真实链路**：`server\devdb.ps1 start -Port 3417` → `server\build\hospital-server.exe serve <dsn> --port 8091`（带 `SSL_CERT_FILE`）→ `curl /health` → App 切「在线服务」→ 真实登录/分诊（`source=model`）/挂号/就诊 → 医生端接诊 → 管理端看板（真实计数）。
3. **起库、起服务、`/health` 的终端画面留 3–5 秒**（这是"能装能跑"的最硬证据）。
4. **字幕放到底部安全区**：给画面预留 8–10% 的底部黑边（或把 UI 缩到 90% 高度），字幕只压黑边。
5. **导 1920×1080（16:9）H.264 + AAC**，响度 −16 LUFS，体积控制在 80 MB 内；若必须保留 3:2 画面，就左右补黑边而不是上下压字。
6. 片头 2–3 秒写清版本与提交（`0.2.0-p1 / v0.2.0-p1-rev`），片尾 2 秒放仓库地址。
7. 导出后用 `ffprobe` 复核：`h264 / 1920x1080 / 30fps / yuv420p / aac 48k`，再抽查 5 帧确认字幕不压 UI。

## 六、复现本次转码的命令

```powershell
# 1) 3 秒说明卡（1920x1280，深绿底）
ffmpeg -f lavfi -i "color=c=0x0E2A28:s=1920x1280:r=30:d=3" -f lavfi -i "anullsrc=r=44100:cl=stereo" -shortest `
  -vf "drawtext=fontfile='C\:/Windows/Fonts/msyhbd.ttc':text='本片画面全部来自「演示数据（Mock）」模式':fontcolor=0xB8F0E4:fontsize=64:x=(w-text_w)/2:y=430, ..." `
  -c:v libx264 -profile:v high -level 4.1 -pix_fmt yuv420p -crf 20 -c:a aac -b:a 128k -ar 48000 card.mp4

# 2) 拼接 + 重编码 + 响度归一化
ffmpeg -i card.mp4 -i raw.mp4 -filter_complex "[0:v]scale=1920:1280,setsar=1,fps=30[v0];[1:v]scale=1920:1280,setsar=1,fps=30[v1];[v0][v1]concat=n=2:v=1:a=0[v];[0:a]aresample=48000,aformat=channel_layouts=stereo[a0];[1:a]aresample=48000,aformat=channel_layouts=stereo,loudnorm=I=-16:TP=-1.5:LRA=11[a1];[a0][a1]concat=n=2:v=0:a=1[a]" `
  -map "[v]" -map "[a]" -c:v libx264 -profile:v high -level 4.1 -pix_fmt yuv420p -crf 23 -preset medium `
  -c:a aac -b:a 128k -ar 48000 -movflags +faststart harmony-demo-1080p-h264-with-notice.mp4
```
