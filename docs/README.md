## 三、本地开发手册（不入库，评审无关）

这几份是**写代码时查的操作手册**，已在 `.gitignore` 里排除，只在本地克隆的工作区存在。
仓库里不放它们：评审用不上，且会随源码一起漂。需要时向团队要，或按文件名在内部资料里取。
