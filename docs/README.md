## 四、数字的唯一来源
[交付快照.md](交付快照.md) 是版本、体积、哈希的唯一锚点，由 `tools/check-snapshot.ps1` **机器校验**；断言数由 `server/tests/doc-counts.ps1` 对账，任何一处数字变动先跑这两个脚本再提交。这两个脚本硬编码了若干路径（`README.md`、`docs/项目说明.md`、`docs/系统设计.md`、`docs/部署说明.md`、`docs/adr/ADR-0001-号源与挂号独立MySQL路径.md`、`docs/交付快照.md`）：**这几份不能挪位置**，挪了门禁会红。
