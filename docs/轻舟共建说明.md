# 轻舟（QingZhou）共建说明：我们参与开发的框架，不是"拿来就用的第三方"

> 一句话：**轻舟是本团队参与开发的仓颉 Web 框架**。本作品因此同时具备两层产出——**框架侧的设计与实现**，以及**跑在这个框架上的完整医疗业务闭环**。
> 本文只写"能核对"的东西：每条结论给出仓库内证据（`路径:行号`、提交哈希），上游相关的部分给出核对方式，不夸大、不把"使用"说成"自研"。
