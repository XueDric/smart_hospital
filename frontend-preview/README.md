# 智慧医院 · 前端预览（frontend-preview/）

纯静态、零依赖的三端交互预览页。直接用浏览器打开 `index.html` 即可运行，无需构建、无需起服务。

> **v2**：设计规范已全面对齐 `docs/frontend-preview.html` 走查稿（设计令牌、信息架构、业务红线逐项比对改造）。


## 三端说明（对齐走查稿信息架构）

| 端 | 适配 | 覆盖页面 |
| --- | --- | --- |
| 患者端 | 手机屏幕（≤480px 全屏，宽屏显示圆角手机壳） | 登录（dev_auth 警告）、智能分诊、预问诊、约号、我的预约、我的（就诊记录、设备管理）；**5 Tab 底部导航，无首页/公告页** |
| 医生端 | 手机屏幕（同患者端） | 登录、接诊队列（序号列表 + 全部/候诊/接诊中/已完成筛选）、七段式电子病历（字数计数、仅诊断/处理意见必填锁定、锁定后只读）、我的 |
| 管理端 | 桌面浏览器（仿浏览器框 + 深色侧栏） | 运营看板（聚合卡片 + 渐变柱状趋势图）、科室管理、医生管理、排班/号源、账号管理、AI 能力中心、知识库 |

顶部工具栏可在三端之间切换。

## 业务红线（预览中机制性还原）

- 危急征象弹层**不复述命中关键词**，仅引导急诊/120
- 病历 `required_to_lock` 仅「诊断 / 处理意见」两段；`missing_required` 非空不可锁定；锁定后只读（409 EMR_LOCKED），仅管理员 reopen
- 就诊记录列表**不含病历正文**；草稿未锁定一律 404 EMR_NOT_FOUND
- 挂号确认弹窗携带 `client_token`；重复同一单返回 200 幂等
- AI 密钥仅接受 `env:`/`file:` 引用，裸密钥机制性拒绝
- 运营看板只出聚合计数，响应不含任何 patient_id / doctor_id / phone / name
- 脱敏：患者手机号在医生端显示为 `138****0621` 形态

## 交互覆盖

- **导航切换**：患者/医生端 5 Tab 底部导航 + 页面前进/返回；管理端深色侧边栏
- **表单校验**：登录（手机号/工号 + 密码）、病历必填两段、科室编码重复校验、AI 密钥引用格式、号源余号 0 禁选
- **动态内容**：分诊（危急征象兜底 → 急诊提示；关键词 → 推荐科室与号源卡）、预问诊 6 槽位进度卡 + 快捷「无」、约号筛选栏、预约记录分段筛选（ upcoming / done / canceled ）
- **状态机**：挂号后退号释放号源；医生 booked→visiting→done，完成就诊前必须已锁定病历

## 【预览专用】标注约定

仅在开发预览中展示、实际软件中不会出现的文字或元素，统一用三种方式标注：

1. **可见徽标**：紫色虚线「预览专用」小标（`.preview-badge`，鼠标悬停有说明）
2. **HTML 注释**：`<!-- 【预览专用】 ... -->`
3. **JS/CSS 注释**：`/* 【预览专用】 ... */`

典型预览专用元素：顶部工具栏与三端切换器、手机壳与模拟状态栏、管理端仿浏览器框、登录页 dev_auth 警告、全部 Mock 数据与身份。
